🛠️ Integration Considerations
• Weight Management: Ensure the total weight, including all components, does not exceed the frame's payload capacity to maintain optimal flight performance.
• Power Distribution: Use a reliable power distribution board to manage power supply to all components, ensuring voltage and current requirements are met.
• Cooling Solutions: Implement adequate cooling for the Jetson Orin Nano to prevent overheating during intensive processing tasks.
• Vibration Dampening: Mount sensitive components like the LiDAR sensor and onboard computer on vibration-dampening materials to ensure data accuracy and component longevity.
• Note: Quadcopter configuration has no motor redundancy. Max recommended takeoff weight ~2.5kg for safe operation. Suitable for moderate wind and agricultural use.



Drone Sawit Hexacopter Integration Guide
📦 1. Mechanical Assembly
StepTask1.1Assemble the Tarot Iron Man 680 Pro frame according to the manual. Ensure arms are secured and fold mechanisms locked.1.2Mount A2212 1000KV motors on each arm using the included screws and thread locker. Orient CW/CCW correctly.1.3Install ESCs on the arms or inside the frame. Secure with zip ties or double-sided tape.1.4Mount the Pixhawk flight controller using vibration-dampening foam or a shock-absorbing platform at the center.1.5Mount the Jetson Orin Nano inside a protective case (e.g., aluminum) on top of the frame or payload plate.1.6Mount LiDAR on front-facing vibration isolation bracket, and the sprayer system below the drone CG (center of gravity).1.7Route propeller wires and battery cable cleanly. Label wires if needed.1.8Attach 1045 propellers, ensuring matching CW/CCW direction with motor spin. Torque lightly.
🔌 2. Electrical Wiring
StepTask2.1Connect ESC signal wires to Pixhawk (MAIN OUT 1–6).2.2Connect ESC power input (red/black) to the Power Distribution Board (PDB).2.3Solder or plug XT60 from the battery into PDB. Verify polarity!2.4Power Jetson Orin Nano via separate 5V/4A BEC or 2S-4S regulator from battery.2.5Connect Pixhawk Power Module to battery and plug into Pixhawk’s power port.2.6Plug GPS/Compass module into Pixhawk (I2C + Serial). Mount away from power wires.2.7Connect LiDAR (UART/I2C) to Jetson (for SLAM or Altitude Hold) or Pixhawk directly (depending on use).2.8Optional: Connect telemetry radio to Pixhawk TELEM1, and USB/UART link between Jetson and Pixhawk for MAVLink control.
⚙️ 3. Software & Configuration
StepTask3.1Flash ArduCopter or PX4 firmware to Pixhawk using Mission Planner or QGroundControl.3.2Calibrate: Accelerometer, Compass, RC, ESC, Radio Failsafe.3.3Configure motor order (1–6) and verify motor direction (adjust in ESCs if reversed).3.4Set flight mode: Stabilize, AltHold, Loiter, Auto. Tune PID values for 4S + A2212 + 680 frame.3.5Flash JetPack on Jetson Orin Nano. Install: ROS2, MAVROS, OpenCV, YOLOv8, or your vision pipeline.3.6Enable MAVLink communication between Jetson and Pixhawk for companion control (telemetry, commands, mission injection).3.7Integrate sprayer trigger via PWM relay (connected to Pixhawk AUX OUT 1 or Orin Nano GPIO). Test logic high → spray.
🔋 4. Power & Load Testing
StepTask4.1With propellers OFF, test power-up sequence. Check ESC arming tone, Pixhawk LED status, Jetson boot.4.2Connect to Mission Planner → confirm GPS lock, battery voltage, sensors.4.3Arm motors without props and test throttle response.4.4Weigh drone with battery, Jetson, sprayer filled. Confirm TWR < 2.2 kg, or adjust prop size/motor.4.5Perform hover test in Stabilize/Loiter mode. Trim as needed.4.6Record current draw and flight time to validate ~20 minutes goal.
🧠 5. AI Inference Pipeline (Orin Nano)
StepTask5.1Setup USB or CSI camera, mount on forward bracket.5.2Install YOLOv8 or custom trained model (for tree detection, flower identification).5.3Run inference on captured frames. Trigger sprayer GPIO if detection confidence > threshold.5.4Log detections + timestamps (optional: export to SD card).5.5Optional: overlay inference box on GStreamer live video to GCS.
🧯 6. Safety Checklist
• ✅ Calibrate compass far from interference.
• ✅ Use thread lock on all screws.
• ✅ Double-check battery polarity before connection.
• ✅ Enable failsafe (low battery, RC loss).
• ✅ Keep prop guards if flying in dense plantation.
