# Bahan riset

Folder ini menyimpan paper, gambar referensi, dan model Simulink yang dihimpun selama pengembangan. Bahan tersebut membantu memahami pendekatan, tetapi angka performa motor, sensor, detector, atau dosis di dalam paper tidak otomatis berlaku untuk drone ini.

Periksa sumber dan izin distribusi setiap dokumen sebelum membagikannya. Catat paper mana yang mendukung keputusan desain di dokumen teknis proyek.
