# Prototype Jetson/Pixhawk/Arduino (arsip)

Kumpulan eksperimen lama untuk perencanaan misi, AI, MAVSDK/MAVLink, Pixhawk, dan firmware Arduino. Banyak nama modul menggambarkan fitur yang direncanakan, tetapi tidak membuktikan integrasi atau pengujian end-to-end. Baca [`README_ORIGINAL.md`](./README_ORIGINAL.md) dan [audit repo](../../docs/PROJECT_AUDIT.md).

Sumber asli dipertahankan langsung di folder ini. Environment Windows yang pernah ikut tersimpan di dalam repo telah dikeluarkan. File `jetson/requirements.txt` adalah kebutuhan prototype dan belum divalidasi untuk Ubuntu 22.04.

Jangan gunakan untuk uji terbang: sebagian modul adalah stub, dan kapasitas F450/payload belum terukur.
