# Arduino Firmware for Drone Sawit

## Build & Upload Instructions

1. Open the Arduino project files in the Arduino IDE or PlatformIO.
2. Select the correct board (e.g., Arduino Uno, Nano, or as specified in the source code).
3. Install the required libraries:
   - List all libraries used in your code (e.g., Servo, Wire, Adafruit Sensor, etc.)
   - Use the Arduino Library Manager or PlatformIO to install them.
4. Connect your Arduino board via USB.
5. Build and upload the firmware.

## Required Libraries (example)
- Servo
- Wire
- Adafruit Sensor
- Any others used in your code (check the `#include` statements)

## Notes
- Ensure the correct COM port and board settings are selected.
- Refer to code comments for pin mappings and configuration.
- For troubleshooting, see the main project `README_DEPLOYMENT.md`.
